## 📌 Overview

Comprehensive sales analysis of **113,036 transactions** across **6 countries** from **2011 to 2016**, tracking over **$85.7M** in total revenue with full cost and profit breakdown.

Built using **Microsoft Excel** with Pivot Tables, dynamic charts, and calculated fields.
